# 回測重播

單檔網頁(index.html),用 Binance USDT-M 公開行情做回測重播。紀錄與設定只存在使用者自己的瀏覽器。

## 上傳到 GitHub Pages
1. GitHub 右上角 + → New repository,名稱例如 backtest,選 Public,建立。
2. 點 uploading an existing file,把 index.html、.nojekyll、README.md 拖進去,Commit。
3. Settings → Pages → Source 選 Deploy from a branch,Branch 選 main、資料夾 / (root),Save。
4. 約 1 分鐘後網址:https://你的帳號.github.io/backtest/

注意:index.html 內含內建的強勢標的名單資料;Public repo 任何人都看得到。
